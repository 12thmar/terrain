Why we're building this

Context

Thomas at Red Drum Roasters told us he won't buy without full sourcing transparency — farm, washing station, and a price breakdown showing what each party in the chain earns. He currently pays $6.55/kg for a G2 Guji traceable to the washing station manager and individual farmers. He'd pay $9–$20/kg for excellent coffee with the same transparency.

"I'd be happy to talk more in the future if there are developments in the Buna Roots model… I'd love to chat again when you're getting there." — Thomas, Red Drum Roasters, Oct 27 2026

Terrain is the answer. A multi-tenant supplier portal where importers like Bunaroots onboard their suppliers, who register farms with GPS-tagged photos, link washing stations, and submit per-lot cost breakdowns. Bunaroots is customer #1. Any importer can use it.

Roadmap

Implementation Phases

1

Odoo Addon — terrain_sourcing (buna-serat)

  • All 7 models built with fields, relationships, and security rules
  • Addon deployed to buna-serat and installed at crm.bunaroots.com
  • GitHub Actions CI wired (OIDC role: buna-serat-github-deploy) — triggers on addons/** and deploy/**
2

App Scaffold — terrain repo

  • Laravel backend: Google OAuth + supplier auth (AuthController, RequireSupplierAuth middleware, Supplier model)
  • React frontend: Login page, Dashboard, Layout — client-side navigation
  • Docker Compose (dev + prod), Dockerfile, nginx config, entrypoint with auto-migrate
  • GHA deploy pipeline: OIDC → IAM role → SSM → EC2 (working)
  • S3 upload endpoint — UploadController POST /upload/photo, league/flysystem-aws-s3-v3
  • Farm registration form + PhotoUpload component (exifr EXIF GPS extraction)
  • FarmController POST/GET /farms — Farm + FarmPhoto models + migrations
  • Dashboard farm grid with cover photo and state badge
3

Database Foundation + Farm Location

  • 🚨 Switch SQLite → Neon PostgreSQL + PostGIS — data wipes on every deploy today
  • Enable PostGIS extension on Neon — enables spatial queries for all ET farms
  • Leaflet.js map — manual GPS pin when photos have no EXIF
  • Farm profile page — view registered farm with photos and map pin
4

Farmer + Washing Station

  • Farmer profile form (linked to farm, photo upload)
  • Washing station registration form
  • Many-to-many farm ↔ washing station linking UI
5

Lots + Price Breakdown

  • Coffee lot submission form (grade, process, harvest date)
  • Price breakdown form — % to farmer, washing station, importer, shipping
  • Read-only public traceability URL per lot
6

Surface on bunaroots.com

  • Pull lot + farm data from Odoo API into buna-sinni product pages
  • Roasters see full chain before buying
  • Thomas's question answered on the page
7

Ethiopia Scale

  • Public map — every registered farm in Ethiopia, filterable by region, grade, process
  • PostGIS spatial queries — "farms within 50km", regional density heatmap
  • Mobile-first offline API — field workers register farms without internet, sync when connected
  • Multi-tenant expansion — other Ethiopian exporters can onboard as customers
  • Open farm registry — partner with ECX / ECTA to make data public and verifiable
  • Terrain becomes the standard identity layer for Ethiopian coffee farms
